### Systems & Documents
The API interacts with various backend and external systems to enable seamless document processing and automation. Each system represents a distinct environment, service, or module that the platform integrates with to provide end-to-end functionality.

**Document Payload Requirements**
- **Maximum size:** 10 MiB per document
- **Supported MIME types:**
    - `application/pdf`
    - `image/jpeg`
    - `image/png`
    - `image/tiff`
- Documents must not contain security restrictions (e.g., password protection)
- Recommended resolution: 640 × 480 pixels for best results

**Key Capabilities**
- **Data Sources** – Connect and retrieve information from multiple storage and document systems
- **Processing Engines** – AI-powered extraction, verification, and transformation of document data
- **Workflow Integrations** – Interact with internal and external workflow systems for task orchestration
- **Monitoring & Reporting** – Access system health, activity logs, and operational metrics in real-time

**Access and Security**
- Only authorized clients can interact with systems (**401 Unauthorized** if missing)
- Role-based access ensures actions are permitted according to user privileges (**403 Forbidden** if restricted)
- Requests must comply with payload specifications (**400 Bad Request** for invalid inputs)

**Best Practices**
- Use standard endpoints for all system interactions
- Handle system errors and connectivity issues gracefully
- Limit request frequency to prevent overloading integrated systems
